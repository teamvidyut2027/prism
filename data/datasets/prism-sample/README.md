# prism-sample

Synthetic visual-reasoning benchmark generated by **Prism** (Visual Task Factory).

* Tasks: 116 (30 base scenes + variants)
* Questions: 220 (100% gold answers cross-checked against an independent pixel verifier)
* Families: bars, lines, shapes, clocks, mazes, tables
* Seed: 42; rebuilding with the same config reproduces identical images.

## Files
* `tasks.jsonl`: one task per line (scene, manifest, questions, gold + verified answers)
* `images/<image_id>.png`
* `dataset.json`: config, rejection funnel and statistics
